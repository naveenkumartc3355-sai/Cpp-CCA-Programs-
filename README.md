# C++ CCA — 20 Programs

This repository contains 20 separate beginner-friendly C++ programs covering:
- Arrays (01–04)
- Enum (05–08)
- Structure (09–12)
- Pointers (13–16)
- Union (17–20)

## How to compile and run
Each `.cpp` file is a separate program with its own `main()` function. Compile one file at a time.

Using g++:
```bash
g++ 01_array_display.cpp -o program
./program
```
On Windows, run `program.exe` after compilation.

## Suggested GitHub demonstration
Open the repository, select a `.cpp` file, and show the code. To demonstrate output, run that file in VS Code or an online C++ compiler. Commit changes when you update code.

## Important
These are learning examples. Review and practise explaining each program before submitting it. The output of `sizeof` can vary by compiler/platform.
